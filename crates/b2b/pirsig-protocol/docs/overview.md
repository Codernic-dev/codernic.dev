# Pirsig Protocol Overview

This crate defines the underlying health check and cryptographic signature verification mechanisms for the B2B Pirsig Module. It contains essential structures for processing health requests/responses and implements HMAC-SHA256 signature generation and validation to ensure communication integrity.
