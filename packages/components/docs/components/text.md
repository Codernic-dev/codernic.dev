# Text Typography Component

Standardized typography primitive enforcing the signature 3-font hierarchy: **Outfit** (Headings), **Inter** (UI/Body), and **JetBrains Mono** (Code/Terminal).

## Live React Component Render

<ReactSpecimen componentName="text" />

## Usage

```tsx
import { Text } from '@codernic/components/atoms';

<Text variant="h1">Heading Level 1 (Outfit)</Text>
<Text variant="body">Body text rendered in Inter typography.</Text>
<Text variant="code">cargo run --bin isis-toolbox</Text>
```
